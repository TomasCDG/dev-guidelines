# dev-guidelines — reglas para el agente en este repo

- **Commits:** no propongas commits ni preguntes por ellos durante el trabajo. Se commitea solo al terminar una task o subtask, y cuándo lo decide el desarrollador: commitea únicamente cuando lo pida.
- `skills/dev-setup/scripts/` y `skills/dev-setup/assets/` se generan: edita las fuentes (`dev-template/`, `scripts/`, `release/`) y ejecuta `python -I scripts/build-skill.py`.
