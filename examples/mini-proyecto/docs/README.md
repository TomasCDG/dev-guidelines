## 1. Cómo usar este índice

- Antes de tocar el código de un área, busca aquí su página y léela.
- Toda página nueva se registra en la tabla en la misma subtask que la crea.
- «Estado»: `vigente` u `obsoleta`. «Verificado contra»: commit o fecha de la última comparación con el código.
