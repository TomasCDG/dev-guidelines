## 1. Cómo usar este índice

- Antes de tocar el código de un área, busca aquí su página y léela (columna «léela cuando…»).
- Toda página nueva se registra en la tabla de la sección 3 en la misma subtask que la crea.
- «Estado»: `vigente` u `obsoleta`. «Verificado contra»: commit o fecha de la última comparación con el código.
- Una página `obsoleta` se contrasta con el código antes de usarla.
- Plantilla de página: [_page-template.md](./_page-template.md). Vocabulario: [glossary.md](./glossary.md).
